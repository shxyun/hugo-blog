最近刷到一个挺热的话题：有报道称，一位明星在节目里自曝长期喝蛋白粉，体检时肾脏状态被形容得像「70岁」。话题很快冲上热搜，评论区里最集中的一个疑问是——喝蛋白粉，真的会损伤肾脏吗？

先把话说在前头：这是当事人在节目/访谈里的个人说法，属于个案自述，不能直接当成「蛋白粉伤肾」的证据。而且，围绕这位明星肾脏的旧说法，最早出现在 2019 年他婚前体检相关的节目里，据早年港媒报道（二手来源，尚未进一步核实），其家人解释的主因是「常年习武受伤、长期服用止痛药」，并不是蛋白粉。同一件事，前后口径并不一样，本身也说明成因可能不止一个。所以这篇不碰八卦，只把「中老年人到底要不要补蛋白粉」这件事讲清楚。

### 蛋白粉到底是什么

据新华网转载的媒体介绍，蛋白粉一般是提纯的大豆蛋白、酪蛋白、乳清蛋白或它们组合而成的粉剂，用途是给蛋白质摄入或吸收不足的人补充蛋白质。说白了，它不是「补品」，更像一种「浓缩的蛋白质来源」——本质和鸡蛋、牛奶、瘦肉、豆制品里的蛋白质是一回事，只是被提纯、做成了粉。

### 健康人吃蛋白，证据怎么说

对健康成年人来说，目前的研究证据，并不足以证明适量或偏高一些的蛋白摄入会损害肾功能。多项系统综述和荟萃分析观察到：高蛋白饮食短期内可能让肾脏滤过率略有升高，但这多被看作身体的一种生理性适应，长期到底有没有影响，目前还没有定论。

这里有个关键的区分：同一句「多吃蛋白」，放在不同人身上，意义完全不同。对肾功能已经下降的人，或者本身属于高风险的人，高蛋白饮食可能增加肾脏的「工作负荷」，需要格外当心；但对肾功能正常的健康人，现有证据并不支持「多吃点蛋白就会把肾吃坏」这种说法。

### 指南其实一直在强调两件事

中国营养学会《中国居民膳食指南（2022）》给的，是一整套「怎么吃够」的建议：鱼、禽、蛋、肉平均每天 120~200 克，奶 300 毫升以上，大豆及坚果 25~35 克。指南给出的成人蛋白质参考摄入量约为男性每天 65 克、女性每天 55 克；2023 版的《中国居民膳食营养素参考摄入量》还提高了 65 岁以上老年人的蛋白质推荐量。

科普中国辟谣平台也在提示：不能简单认为「吃蛋白粉就会增加肾脏负担」，是否构成负担，要看长期从各种渠道摄入的蛋白总量，会不会超过个人肾脏的处理能力。指南提倡的是「提高优质蛋白的比例」，而不是无节制地增加蛋白总量。

换成大白话：核心不是「要不要吃蛋白粉」，而是「你一天到底吃了多少蛋白、你的肾能不能处理得过来」。

### 谁可能需要补，谁要慎补

对大多数人来说，蛋白质最好的来源还是日常食物。下面这张表，帮你对号入座——注意，它只是「要不要留个心」的提示，不是用量或用药建议：

| 人群特征 | 提示 |
|---|---|
| 日常吃不下肉蛋奶、整体饭量偏少 | 先看整体饮食，必要时再考虑补充 |
| 长期以主食为主、优质蛋白来源少（如素食者） | 可先调整食物结构，必要时再考虑补充 |
| 运动量大、健身增肌 | 结合每日蛋白总摄入量一起看 |
| 老年人咀嚼、消化差，吃肉偏少 | 优先从三餐食物里补，别一上来就靠粉 |
| 健康成人、三餐均衡 | 一般无需额外补充 |
| 慢性肾脏病／肾功能不全 | 慎补，遵医嘱、按分期控制蛋白总量（参见 WS/T 557—2017） |
| 肝病（肝硬化、肝性脑病） | 慎补，先咨询医生 |
| 痛风／高尿酸 | 慎补，先咨询医生 |
| 对成分过敏、急性胰腺炎、胃肠功能衰竭 | 不宜自行补充，先咨询医生 |

这张表只是帮你判断「该不该留个心」。真要补充，先看自己的整体饮食；尤其是有基础病的人，别自己拍板。

### 几个常见误区

- **误区一：蛋白粉是「保健品」，多吃点总没坏处。** 蛋白质也是营养素，吃进去的量要算总账，不是越多越好。
- **误区二：只要喝蛋白粉就必然加重肾脏负担。** 这种说法缺乏依据，关键看摄入总量和个体情况。
- **误区三：老人吃肉少，就该多补蛋白粉。** 很多长辈其实是整体吃得太少，先要想办法把三餐吃好、吃均衡，而不是只盯着蛋白粉。

### 出现这些情况，别硬扛，及时就医

如果家里人出现眼睑或下肢水肿、尿量明显变化、尿里泡沫多且久久不散、莫名乏力等情况，别自己猜是不是「蛋白吃多了」，也别对照网上的说法吓自己，直接去医院查一查，交给医生判断。慢性肾病患者的蛋白质摄入，应当由医生结合分期和身体状况来定——行业标准 WS/T 557—2017 也是按不同分期分别给出建议的，绝不是照搬一个数字那么简单。

### 写在最后

明星的体检结果，是他个人的事；我们能做的，是把「要不要补蛋白粉」这件事想明白。对中老年朋友和替父母操心的子女来说，先好好吃饭、把三餐里的优质蛋白安排上，比急着下单蛋白粉更实在。真要补，也请先看清自己的饮食全貌，有必要时听听医生的意见。

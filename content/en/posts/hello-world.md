## Welcome

This blog is built with **Hugo + PaperMod** and deployed on Cloudflare Pages.

- Write Markdown locally
- `git push` for automatic deployment
- Global CDN with automatic HTTPS

### Code Example

```python
print("Hello, Hugo!")
```

### Image Reference

Place images in `static/images/`, then reference them:

```markdown
![Demo Image](/images/demo.png)
```
